# Security Policy

## Supported Versions

Only the latest release of the plugin receives security updates. Please keep your installation up to date via the [Releases](https://github.com/Ebioro-UAB/ebioro-payment-woocommerce/releases) page.

## Reporting a Vulnerability

Please **do not open a public GitHub issue** for security vulnerabilities.

Report them privately to **support@ebioro.com** with:

- A description of the issue and its impact
- Steps to reproduce (a proof of concept helps)
- The plugin version and WordPress/WooCommerce versions involved

We will acknowledge your report within 5 business days and keep you informed while we work on a fix. Please give us reasonable time to release a fix before any public disclosure.

## Scope

This policy covers the code in this repository (the WooCommerce plugin). Vulnerabilities in the Ebioro platform itself should also be reported to support@ebioro.com.
